# Voice-Controlled Smart Car with Obstacle Avoidance

An Arduino-based robotic car designed to support obstacle avoidance and remote control through Bluetooth or serial commands generated by a voice-control application.

## Overview

This project uses an Arduino Uno, an L293D-compatible motor shield, an ultrasonic distance sensor, and a servo motor to build a four-motor robot car.

The firmware supports three selectable operating modes: automatic obstacle avoidance, Bluetooth control, and voice-command control through serial input. Only one mode runs at a time.

## Features

- **Obstacle Avoidance:** Measures distance using an ultrasonic sensor and maneuvers when an obstacle is detected.
- **Bluetooth Control:** Supports movement commands received over a serial connection from a Bluetooth interface.
- **Voice-Command Control:** Accepts predefined characters sent by a compatible voice-control application.
- **Servo-Based Scanning:** Turns the ultrasonic sensor to compare distances on the left and right.
- **Four-Motor Control:** Uses an AFMotor-compatible motor shield to control the robot's motors.

## Hardware Components

| Component | Purpose |
|---|---|
| Arduino Uno | Main controller |
| L293D-compatible motor shield | Controls four DC motors |
| HC-SR04 ultrasonic sensor | Measures obstacle distance |
| Servo motor | Turns the sensor for directional scanning |
| HC-05 Bluetooth module | Optional wireless serial control |
| Four DC motors and robot chassis | Movement |

## Operating Modes

Select the mode near the beginning of `src/smart_car.ino`:

```cpp
#define CONTROL_MODE 1
```

| Value | Mode | Description |
|---|---|---|
| `1` | Obstacle avoidance | Automatically detects obstacles and chooses a direction |
| `2` | Bluetooth control | Receives movement commands over serial |
| `3` | Voice-command control | Receives command characters from a compatible application |

Only one operating mode is active at a time.

## Control Commands

### Bluetooth Mode

| Character | Action |
|---|---|
| `F` | Forward |
| `B` | Backward |
| `L` | Left |
| `R` | Right |
| `S` | Stop |

### Voice-Command Mode

| Character | Action |
|---|---|
| `^` | Forward |
| `-` | Backward |
| `<` | Left |
| `>` | Right |
| `*` | Stop |

Voice recognition is handled by the external application. The Arduino firmware receives the corresponding characters; it does not perform speech recognition itself.

## Sensor Connections

| Component pin | Arduino connection |
|---|---|
| HC-SR04 Trig | A1 |
| HC-SR04 Echo | A0 |
| Servo signal | D10, subject to motor-shield compatibility |
| HC-05 serial connection | Must match the selected serial interface |

**Important:** Verify the exact motor shield pin assignments before connecting the servo. Some shields use digital pin 10 internally, which can conflict with servo control. Check the HC-05 serial wiring and USB serial requirements before selecting Bluetooth mode.

## Safety and Limitations

- The firmware has not been independently verified on every hardware configuration.
- Ultrasonic readings can be affected by surface angle, distance, and environmental conditions.
- The Bluetooth and voice-command modes require a compatible serial connection and an application that sends the expected characters.
- Test the robot with its wheels lifted before performing floor tests.

## Future Improvements

- Improve obstacle scanning and sensor error handling.
