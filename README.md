

# Voice-Controlled Smart Car Using Arduino and Bluetooth

## Overview
This project demonstrates a voice-controlled smart car built using an Arduino Uno and an HC-05 Bluetooth module. Voice commands captured by a mobile phone are transmitted wirelessly to the Arduino, which controls the car's movement.

## Objectives
- Develop a car controlled through voice commands.
- Establish Bluetooth communication between a mobile phone and Arduino.
- Control vehicle movement using a motor driver.
- Explore embedded systems and wireless control applications.

## Hardware Components
- Arduino Uno
- HC-05 Bluetooth module
- Motor driver
- DC motors and wheels
- Four-wheel chassis
- Rechargeable battery
- Mobile phone with microphone

## Working Principle
1. The mobile phone captures the user's voice command.
2. The command is transmitted to the Arduino through the HC-05 Bluetooth module.
3. The Arduino interprets the received command.
4. The motor driver controls the motors to move the car forward, backward, left, or right.

## Features
- Hands-free vehicle control through voice commands
- Bluetooth-based wireless communication
- Microcontroller-based motor control
- Practical application of embedded systems

## Challenges and Future Improvements
- Improve command recognition in noisy environments.
- Optimize power consumption.
- Explore enhanced voice recognition and GPS-based navigation.
